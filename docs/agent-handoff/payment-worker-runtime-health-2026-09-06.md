## 6. 重要设计决策

- 仅在 MCP 能提供服务端字段投影或脱敏摘要时，才继续运行时健康核验。

## 8. 验证方式与结果

- 目标环境：`cloud1-d9gc800bmc6952073`，沿用本会话已成功绑定的 CloudBase MCP 环境。
