# bp_version 品牌视觉规范

本规范严格依据附件 `微信图片_20260805120545_175_351-1-1.jpg` 建立，后续原型页面不得引入森林绿、芥末黄、棕色或其他偏离该参考图的主色方向。

实现入口：`bp_version/theme.css`。本文件定义设计规则，`theme.css` 是唯一执行这些规则的品牌样式文件。

## 色彩 Token

参考图明确标注了四个基础色：`#D3E8F4`、`#FFE0E6`、`#FFFCF4`、`#FFBCBD`。实现时使用以下 OKLCH Token，并以这四个颜色作为唯一调色来源：

- `--bg`: `oklch(92.7% .045 225)`，对应 `#D3E8F4`，全局页面背景与大面积底色
- `--surface`: `oklch(98.8% .014 88)`，对应 `#FFFCF4`，卡片、内容面、底部操作栏背景
- `--fg`: `oklch(32% .035 165)`，由四个基础色推导出的深蓝绿正文色，用于标题和主要文字
- `--muted`: `oklch(56% .025 165)`，由正文色降低对比度得到，用于辅助文字和说明
- `--border`: `oklch(84% .035 225)`，由 `--bg` 推导，用于分割线、描边和不可选状态
- `--accent`: `oklch(72% .115 16)`，对应 `#FFBCBD`，用于主要强调、价格、选中态和成功标记

### 辅助映射

- `#FFE0E6` → 浅草莓粉：用于次级背景、柔和标签、头像区域和轻量提示
- `#FFFCF4` → 奶油白：用于内容承载面，避免使用纯白
- `#D3E8F4` → 天蓝：用于页面底色、冷色插画块和配送/信息提示背景
- `#FFBCBD` → 珊瑚粉：用于主 CTA、价格、数量标记、选中下划线和状态节点

## 字体系统

- 展示字体：`"Iowan Old Style"`, `"Baskerville"`, `"Songti SC"`, `Georgia`, serif
- 正文字体：`-apple-system`, `BlinkMacSystemFont`, `"SF Pro Text"`, `system-ui`, sans-serif
- 辅助信息：沿用正文字体，通过较小字号、较高字距和 `--muted` 区分层级

## 视觉语言

1. 整个原型使用轻盈、低饱和、奶油草莓牛乳般的氛围，不使用黄棕、森林绿或复古咖啡色。
2. 背景以天蓝为主，内容面以奶油白为主，粉色只做明确而克制的强调。
3. 页面标题使用深蓝绿色以保证可读性，但它必须是由参考图四色推导出的文字色，不得成为品牌主色。
4. 卡片保持现有布局和信息密度，使用浅蓝边界、奶油白面和柔和阴影，不新增装饰性结构。
5. 主要按钮、价格、标签、选中态、成功态和进度节点统一使用珊瑚粉体系。
6. 所有页面、空状态、弹层、订单状态、配送状态和底部操作栏必须共享这套 Token。

## 一句话总结

这是一个以 `#D3E8F4` 天蓝为底、`#FFFCF4` 奶油白为面、`#FFE0E6` 草莓粉为辅、`#FFBCBD` 珊瑚粉为强调的轻甜牛乳风视觉系统。
